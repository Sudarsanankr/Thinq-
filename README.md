# Thinq - Music Videos Streaming App

A modern music videos streaming application built with cutting-edge web technologies.

## Features

- 🎵 Stream high-quality music videos
- 🔍 Advanced search and discovery
- ❤️ Create and manage playlists
- 👥 User authentication and profiles
- 📱 Responsive design for all devices
- 🎨 Beautiful UI/UX
- ⚡ Fast and optimized performance

## Tech Stack

- **Frontend**: React, Next.js, Tailwind CSS
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Authentication**: JWT
- **Video Streaming**: HLS/DASH protocol

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- MongoDB

### Installation

```bash
# Clone the repository
git clone https://github.com/Sudarsanankr/Thinq-.git
cd Thinq-

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local

# Start the development server
npm run dev
```
